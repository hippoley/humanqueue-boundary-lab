## Entrant's real steps
1. Clone this competition-period repository locally, install Git and Node.js.
2. Install the official pack in the project directory: `npx skills add challengepost/learn-ai-basics --all -y`.
3. Open a compatible coding agent (Codex, Claude Code, Copilot, etc.) in the repository and invoke `1-start`.
4. Run `2-scope`, `3-prd`, and `4-spec` interactively. Personally answer the questions raised by the agent. Commit the actual generated `devpost/scope.md`, `devpost/prd.md`, and `devpost/spec.md`; do not manufacture retroactive transcripts.
5. Run `5-build`: compare actual code to the approved spec, implement any missing features and retest. Preserve genuine commits documenting changes.
6. Run `6-ship`: make your own Devpost answers, capture an actual application recording under three minutes, upload it publicly to YouTube or Vimeo, and complete the Devpost application.
7. Cite this public repo and [LICENSE](../LICENSE) in Devpost. Confirm eligibility and age only when true. Complete the final Submit step before the official deadline.
